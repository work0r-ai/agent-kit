# Deep Code / DeepSeek Notes

Deep Code is a DeepSeek-oriented terminal coding assistant that supports Agent Skills.

Install with npm:

```bash
npx @workorai/agent-kit install --agent deepcode
```

Manual user-level skill path:

```text
~/.agents/skills/workorai/SKILL.md
```

Manual project-level skill path:

```text
.deepcode/skills/workorai/SKILL.md
```

Deep Code uses the shared `~/.agents/skills` location for user-level skills, so the default universal install already covers it.
