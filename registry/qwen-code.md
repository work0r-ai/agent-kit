# Qwen Code Notes

Qwen Code supports Agent Skills as folders containing `SKILL.md`.

Install with npm:

```bash
npx @workorai/agent-kit install --agent qwen
```

Manual personal skill path:

```text
~/.qwen/skills/workorai/SKILL.md
```

Manual project skill path:

```text
.qwen/skills/workorai/SKILL.md
```

Qwen Code discovers personal, project, and extension skills. MCP configuration should follow the user's Qwen Code MCP setup.
