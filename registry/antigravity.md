# Antigravity Notes

Antigravity Awesome Skills is a `SKILL.md` playbook library for Antigravity and other AI coding assistants.

Install with npm:

```bash
npx @workorai/agent-kit install --agent antigravity
```

Manual skill path:

```text
~/.gemini/antigravity/skills/workorai/SKILL.md
```

For `antigravity-awesome-skills`, submit the canonical skill folder:

```text
skills/workorai
```

MCP configuration should point to:

```text
https://workorai.com/mcp
```
