# Cursor / Windsurf-Compatible Notes

For clients or hubs that support the common Agent Skills folder convention, use:

```text
skills/workorai
```

Manual project install pattern:

```text
<project>/.agents/skills/workorai/SKILL.md
```

If the client supports Claude-compatible discovery, the same skill folder can also be copied to:

```text
<project>/.claude/skills/workorai/SKILL.md
```

MCP config should point to:

```text
https://workorai.com/mcp
```
