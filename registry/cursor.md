# Cursor Notes

Cursor-compatible Agent Skills use standard `SKILL.md` folders.

Install with npm:

```bash
npx @workorai/agent-kit install --agent cursor
```

Manual personal skill path:

```text
~/.cursor/skills/workorai/SKILL.md
```

Manual project skill path:

```text
.cursor/skills/workorai/SKILL.md
```

MCP configuration should point to:

```text
https://workorai.com/mcp
```
